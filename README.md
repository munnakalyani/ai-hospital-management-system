## 📌 Overview

The **AI Hospital Management System** is a Flask-based web application designed to provide an efficient and intelligent platform for hospital-related management and AI-powered healthcare assistance.

The project combines **web development, data processing, and machine learning** to create a user-friendly healthcare management solution.

The application is designed with a focus on:

- 🏥 Hospital management
- 🤖 AI-powered prediction
- 📊 Data analysis
- 👨‍⚕️ Patient and healthcare workflows
- 🖥️ Simple and responsive web interface
- ⚡ Fast and lightweight Flask architecture

## 📥 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/munnakalyani/ai-hospital-management-system.git
Navigate to the Project Directory:
cd ai-hospital-management-system
python -m venv venv
Create a Virtual Environment:
venv\Scripts\activate
macOS / Linux:
source venv/bin/activate
Install Dependencies
pip install -r requirements.txt
Run the Application:
python app.py
Open your browser and visit:
http://127.0.0.1:5000
📦 Requirements

The project is built using the following technologies and Python packages:

Python 3
Flask
Pandas
Scikit-learn
Joblib
Gunicorn

Install all required dependencies using:

pip install -r requirements.txt
